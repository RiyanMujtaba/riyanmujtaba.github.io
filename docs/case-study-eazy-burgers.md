# Case Study — Eazy Burgers

**Client:** Eazy Burgers — a late-night smash burger joint in Hyderabad, Pakistan
**Type:** Real paid client work · designed, built & deployed end-to-end
**Live:** [eazyburgers.com](https://eazyburgers.com) (custom domain)

---

## The challenge
Eazy Burgers had a following but no real web presence — just an Instagram. They
needed a site that (a) looked as premium as their food, (b) made ordering
frictionless for late-night customers, and (c) built trust with new visitors.

## What I built
A fast, single-page site with a custom identity — not a template:
- **Custom animated hero + menu** that matches the brand's bold, late-night feel
- **Real Google Maps reviews** pulled in for social proof
- **Australian Angus beef** section highlighting what makes them different
- **WhatsApp ordering** — one tap from craving to order, the way locals actually buy
- **Fully responsive** — most traffic is phones, so mobile-first
- Deployed on a **custom domain via Cloudflare**, with web analytics

## The stack
Hand-written **HTML / CSS / JavaScript** (no bloated builder), Cloudflare for
hosting + analytics. Fast load, no dependencies, easy for the owner to trust.

## The result
A live, professional storefront the owner uses as their main link — turning an
Instagram-only business into one with a real, ownable web home and a direct
ordering path.
