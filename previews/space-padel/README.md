# Space Padel — Hyderabad

Single-page brand site for **Space Padel**, a premium padel club on Autobahn Road, Hyderabad.

Built around the club's real black-and-white logo: monochrome palette, the orbit-ring
motif pulled from the badge, and sliced display type (Michroma) echoing the logo lettering.

## Highlights
- Pure black & white, logo-driven design (no invented theme)
- Centred "mission-badge" hero with orbit-ring motif
- Numbered court list, technical spec sheet, scrolling marquee
- Eazy Patties cross-promo (neighbouring venue)
- WhatsApp + Instagram booking, grayscale embedded map
